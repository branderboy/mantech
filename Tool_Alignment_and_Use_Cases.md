# Tool Alignment & Use Cases

*How ManTech's existing, deployed tools map to Mission Assistants. The repositioning invents nothing new. It renames proven tools as the worker who does the job.*

---

## The Analogy: You're Selling Drills. Start Selling The Carpenter.

Right now ManTech sells AI the way a hardware store sells a drill. *"Here's a powerful tool. Here are its features. You operate it."* The buyer has to imagine how it fits their mission, learn to run it, and own the risk if it goes wrong. That's homework, and scared federal buyers don't buy homework.

Mission Workforce Infrastructure sells the **carpenter** instead. You hand over the task. The carpenter shows up with the drill, does the work under your direction, flags anything they're unsure about, and leaves the cabinet built. Same drill. But now it's a teammate doing a job, not a gadget you have to master.

The important part: **ManTech already owns the drills.** Real Property Lifecycle AI, ORI, the Defense Health form automation are real, deployed tools with results. The repositioning builds nothing new. It just stops selling tools and starts selling the assistant who uses them, so the buyer is buying an outcome, not a project.

## The Alignment: Tool → Assistant → Job

| ManTech tool (today) | Becomes this assistant | The job it does | Status |
|---|---|---|---|
| **Real Property Lifecycle AI** | **Cost Estimator** | Builds defensible facility cost estimates, pulls historical + authoritative data, flags uncertain scope for a human, returns an auditable package | Deployed (operational results) |

| **MESA-RA accelerator** | The engine under enterprise assistants | Drops generative AI into existing enterprise services in a secure, governed way | Deployed (DHS + DoD) |
| **AI Sandbox** | Where assistants are built and run | Lets a client build, test, and deploy AI *inside* mission systems, connected or disconnected | Deployed (DoD) |
| **Containerized models + autoscaling** | How assistants run safely | Runs models in restricted/unrestricted and air-gapped environments; scales down when idle | Deployed |

**Honest line:** everything above is real today. The rest of the assistant catalog (Acquisition Researcher, Contract Review, Compliance Analyst, Report Generator, Mission Readiness Analyst, and so on) does **not** map to a shipping tool yet. Those are roadmap, built on the same pattern, fielded only when results justify it. Do not imply they exist.

## The Use Cases (pulled from ManTech's own materials)

### Cost Estimator (Real Property Lifecycle AI)
- Early-stage cost estimate validation and anomaly detection
- Automatic flagging of missing or inconsistent scope
- Parametric estimates informed by similar historical projects
- Facility classification and building category code determination
- Space authorization and requirements analysis
- Clustering similar past projects to benchmark a new estimate
- Spotting cost, scope, and risk drivers across a portfolio
- Structured, auditable planning artifacts with clear rationale

**Results in operational use:** days of research done in minutes; up to 90% less rework; shorter review cycles; more consistent estimates across teams and installations.

### Code Rationalization Assistant (ORI)
- Ingests compiled application artifacts, source, and documentation
- Summarizes, clusters, and maps application functionality
- Documents overlapping and duplicated functions across the enterprise
- Gives stakeholders source-based evidence to retire, consolidate, or modernize

**Outcomes:** fix once instead of patching everywhere; reclaim budget spent twice on the same capability; defensible modernization roadmaps; smaller risk surface.

### Clinician Documentation Assistant (Defense Health Form Automation)
- Automates and checks Reserve Health Readiness Assessment forms
- Streamlines clinician workflows across the Defense Health spectrum

**Outcomes:** more time with patients; fewer documentation errors.

### The platform underneath (MESA-RA, AI Sandbox, containerization)
- MESA-RA: integrate generative AI into existing enterprise services securely; DHS and DoD efficiency gains
- AI Sandbox: build/test/deploy AI directly within mission systems
- Containerized + autoscaling: run in restricted, unrestricted, and disconnected environments

## Why This Alignment Matters For The Pitch

1. **It de-risks the claim.** When ManTech says "Mission Assistants," a skeptic hears vaporware. This table shows each deployed assistant is a tool they can already demo.
2. **It separates real from roadmap, on purpose.** Naming what's deployed vs. what's planned is what makes a federal buyer trust the rest of the list.
3. **It makes the repositioning free.** ManTech doesn't have to build anything to start selling this way. The tools exist. Only the story changes.

**One sentence:** ManTech already has the workers. It's been selling them as tools. Mission Workforce Infrastructure just puts them to work under the customer's command.
